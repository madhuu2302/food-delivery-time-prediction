🍔 Food Delivery Time Prediction

📌 Project Overview
This project predicts food delivery time using Machine Learning techniques. The model analyzes factors such as delivery distance, weather conditions, traffic density, vehicle type, and delivery person characteristics to estimate the expected delivery time.
 🎯 Objective
To develop an AI-based system that accurately predicts food delivery times, helping food delivery platforms improve customer satisfaction and operational efficiency.
 🛠 Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
 📊 Dataset
The dataset contains information related to food delivery orders, including:
- Delivery distance
- Weather conditions
- Traffic density
- Vehicle type
- Delivery person age
- Delivery ratings
- Delivery time
 🔄 Project Workflow
1. Data Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Model Training
6. Performance Evaluation
7. Delivery Time Prediction
🤖 Machine Learning Model
Random Forest Regressor was used to predict food delivery time based on multiple delivery-related factors.
 📈 Results
The model successfully predicts delivery time with good accuracy and can be used to support decision-making in food delivery services.
